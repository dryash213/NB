# AG-UI and generated UI

The current integration status is summarized in the main [README](README.md#agent-and-ui-setup). The built-in agent streams AG-UI events and renders OpenMuse's own small UI payload. It is not a full implementation of Google's A2UI surface protocol. The optional Python bridge is a text-only example and does not inherit OpenMuse's server tools.

For the planned agent workflow, observability, and UI work, see the [agent flow plan](docs/AGENTIC_FLOW_PLAN.md).
